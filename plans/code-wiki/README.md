# Code Wiki 开发计划

本目录保存尚未完成实施和验收的产品设计、目录契约与开发计划，不作为已上线功能的使用说明。计划中的“固定”指拟实现的产品约束，不代表现有生成器已满足。

实际完成范围与验证记录见 [实施进展](EXECUTION_STATUS.md)，不以计划内容代替完成声明。

## 阅读顺序

1. [总体实施计划](CODE_WIKI_EVOLUTION_PLAN.md)：产品边界、联合影响分析、稳定增量、工具校验与分期验收。
2. [页面交互重构计划](CODE_WIKI_UI_REFACTOR_PLAN.md)：三个原有标签、配置复用、进度抽屉和发布审阅。
3. [固定目录规范 v1](CODE_WIKI_DOCUMENT_STRUCTURE.md)：文档结构、归属与入口绑定。
4. [交互设计评审](CODE_WIKI_UX_REVIEW.md)：设计背景与早期探索；与总体计划冲突时，以总体计划为准。

## 文档维护约定

- 待实现的方案及验收清单保留在 `plans/code-wiki/`，随实施更新状态。
- 完成实施并验证实际行为后，再将操作说明、配置说明及必要架构信息整理到项目相应正式文档目录 `docs/` 或 `website-docs/`。
- 不将完整开发计划复制到正式文档，也不将计划描述当作能力已上线的依据。
- 原有 [Code Wiki 实施计划](../../docs/CODE_WIKI_IMPLEMENTATION_PLAN.md) 保留原位置，作为既有实现背景；本次仅调整新增计划，不批量搬迁历史文档。
