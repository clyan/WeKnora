# Tasks

按阶段执行：第 1–4 组为阶段一，第 5–6 组为阶段二，第 7–8 组为阶段三，第 9 组为后续领域阶段。每阶段完成后先交付验收结果；不得以清单勾选代替实际源码与生成质量核对。

本次修订采用轻量主题检查点，不建设独立通用事实数据库。阶段一先完成单主题闭环，再接入有界并发、前端多主题进度与组合验收；按下列依赖顺序推进，不因已有部分基础就提前勾选整项。既有实现应先核对再复用，人工端到端验收由用户执行，实施提供明确步骤和源码对照，不自动触发真实模型任务或发布。
